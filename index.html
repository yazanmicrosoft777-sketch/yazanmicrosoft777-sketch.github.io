SIRI Project Tracker

An internal project-tracking tool of SIRI, a humanitarian organization working in Syria.

What it does

SIRI Project Tracker helps SIRI's own team follow its humanitarian projects: the checklist of each project, deadlines, payments, tasks and the documents that belong to each project.

How it uses Google

The app can keep a backup copy of each project's documents in SIRI's own Google Drive, in a "SIRI" folder. It only uses the limited Google Drive permission that lets it see and manage the files it creates itself. It cannot see any other files in the Drive.

Who can use it

The app is not offered to the public. It is used only by SIRI staff.
