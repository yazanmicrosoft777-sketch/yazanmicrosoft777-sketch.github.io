Privacy Policy

SIRI Project Tracker · Last updated 24 October 2026

SIRI Project Tracker ("the app") is an internal tool used only by staff of SIRI, a humanitarian organization working in Syria. This page explains what the app does with data, including data it receives from Google.

What data the app handles

The app stores SIRI's own project information: project names, checklists, deadlines, payments, tasks, team member names and email addresses, and documents uploaded by SIRI staff. This data is stored on SIRI's own computer.

Google user data

When an administrator connects Google Drive, the app asks Google only for the permission https://www.googleapis.com/auth/drive.file. With it, the app can create, update and move to the bin only the files and folders it has created itself, in order to keep a backup copy of SIRI's project documents in SIRI's own Google Drive. The app cannot see, read or change any other file in the Drive.

The app also reads the email address of the connected Google account, only to show which account is connected.

How Google user data is used and shared

  • Google user data is used only to keep the backup copy described above.
  • It is not sold, not used for advertising, and not shared with anyone outside SIRI.
  • It is not used to train any artificial-intelligence model.
  • The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and protection

The connection to Google is stored only on SIRI's computer that runs the app. Access to the app needs a password.

Removing access and data

An administrator can stop the Drive copy at any time with "Disconnect" in the app's Settings, or by removing "SIRI Tracker" at myaccount.google.com/permissions. The copied files stay in the Drive and can be deleted there like any other file.
